## Нефункціональні вимоги (NFRs Matrix)

| Категорія | Метрика |
|---|---|
| Продуктивність | Latency p95 < 200 мс при 500 RPS (синхронні ендпоінти) |
| Обробка тексту | Асинхронний аналіз до 50 000 символів — не довше 30 с |
| Безпека | OAuth 2.0 / OIDC, JWT, GDPR, OWASP Top 10, Rate Limiting |
| Надійність | Outbox Pattern, Docker, доступність ≥ 99.5%, щоденний backup |
